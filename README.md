# Waqar Ahmed — Professional Portfolio

> Building intelligent systems & cinematic experiences powered by AI.

Welcome to my digital portfolio! I am a multi-disciplinary **AI Engineer, Data Scientist, SEO Strategist, and AI Filmmaker**. This repository holds the source code for my interactive portfolio website.

## 🌟 Overview

The portfolio is engineered to be a seamless, high-performance experience mirroring my professional philosophy: **"Where logic meets storytelling."** It showcases my selected works spanning enterprise data architecture, machine learning pipelines, technical SEO, and cinematic generative AI shorts.

## 🚀 Key Features

* **Apple-Level UI Aesthetics:** A strictly minimalistic, highly structured dark-mode interface featuring dynamic glassmorphism and deep black, neon cyan, and soft gray color palettes.
* **Cinematic Micro-Interactions:** Fully custom, native DOM IntersectionObserver hooks driving smooth scroll-reveals and hover kinematics—without relying on heavy external animation libraries.
* **Optimized Performance:** Bootstrapped via Vite with lightweight dependencies, guaranteeing fast bundle times and instantly responsive page transitions.
* **Real-Time Iconography:** Live API-fetched branding safely pulling strict software SVGs and domain favicons into the styling grid.

## 🛠️ Technology Stack

* **Framework:** React 19 + Vite
* **Routing:** React Router v7
* **Styling:** Pure Vanilla CSS with rigidly scoped CSS Variables and modern flex/grid layouts.
* **Deployment:** Integrated SPA routing config (`vercel.json`) ready for edge-network hosting.

## 🏃‍♂️ Running Locally

To run this project locally, execute the following commands in your terminal:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/waqar-ahmed91/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   *The site will be available on `http://localhost:5173`.*
